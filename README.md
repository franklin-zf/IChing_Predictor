# IChing_Predictor

## 中文

一个探索 QQQ、SPY 等市场指数日内方向和关键点位的 Python 研究项目，组合易经空间映射、量价指标、跳空分析与历史回测。算法说明见 [`PREDICTION_ALGORITHM_DOC.md`](PREDICTION_ALGORITHM_DOC.md)。

安装依赖后可从 `config.example.yaml` 配置数据源，并使用仓库中的分析、预测和回测脚本。预测结果仅供研究，不构成投资建议；历史结果不能保证未来表现。

## English

A Python research project exploring intraday direction and key levels for indices such as QQQ and SPY. It combines I-Ching-inspired spatial mapping, price-volume signals, gap analysis, and historical backtesting. See [`PREDICTION_ALGORITHM_DOC.md`](PREDICTION_ALGORITHM_DOC.md) for the algorithm notes.

Install `requirements.txt`, configure data access from `config.example.yaml`, and use the included analysis, prediction, and backtest scripts. Outputs are for research only, not investment advice; historical results do not guarantee future performance.
